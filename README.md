Windows: pegue o zip das Releases, descompacte, execute install.bat, depois escolha-layout.bat e escolha o que você quiser. Linux: construa a partir do código-fonte. (O exe não é assinado, então o SmartScreen pode reclamar. O código-fonte é público se você preferir construir você mesmo.)

Nota rápida: as capturas de tela usam dados de exemplo (nomes e números da CPU/GPU são apenas marcadores). No seu PC, ele lê seu próprio hardware.

Vou continuar adicionando novos temas e layouts de vez em quando, então fique ligado. Se você tiver ideias, ou quiser fazer seu próprio design, issues e PRs são muito bem-vindos. Não sou afiliado da Thermalright.
